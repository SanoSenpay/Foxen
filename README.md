> **Foxen** — бесплатное расширение с открытым исходным кодом для продавцов FunPay. Оно объединяет AI‑инструменты, настройку интерфейса, автоматизацию рутины, аналитику и автовыдачу в одном рабочем пространстве.
>
> **Firefox Edition:** полный экспорт данных и расширенная настройка звуков.

## 01 — AI-инструменты

| Функция | Что делает |
|:--|:--|
| **AI-ассистент** | Превращает черновик в профессиональное сообщение. |
| **Ответ на отзывы** | Создаёт вежливый ответ в один клик. |
| **Генератор лотов** | Формирует названия и описания в вашем стиле. |
| **Переводчик** | Переводит названия, описания и сообщения. |
| **Генератор изображений** | Создаёт превью лота по текстовому описанию. |
| **Аудит магазина** | Анализирует лоты и отзывы, выдаёт рекомендации. |

## 05 — Чаты, аккаунты и поддержка

- **Чат:** черновики, экспорт истории переписки и быстрый перевод.
- **Аккаунты:** быстрое переключение между несколькими профилями.
- **Покупатели:** метки «свой / чужой», чёрный список и заметки.
- **Поддержка:** тикеты и контроль спорных ситуаций.
- **Диалоги:** имитация набора текста для естественной коммуникации.

## Установка

```text
1. Откройте страницу Foxen в Firefox Add-ons.
2. Нажмите «Добавить в Firefox».
3. Откройте FunPay.
4. Настройте расширение через верхнюю панель.
```
